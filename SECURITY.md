# Politique de sécurité

## Signaler une vulnérabilité

Si vous trouvez une faille de sécurité, **ne la publiez pas dans une issue publique**. Contactez l'équipe par message privé via le dépôt (fonction « Report a vulnerability » de GitHub) ou à l'adresse indiquée sur le profil du dépôt. Nous répondrons dès que possible.

## Ce que nous protégeons

- Les messages analysés par les utilisateurs (voir [confidentialité et sécurité](docs/05_PRIVACY_AND_SECURITY.md)).
- Les clés d'API : elles ne sont jamais écrites dans le code ni dans le dépôt.

## Rappel important

Zero Trust fournit une **estimation**, pas une preuve. Il ne remplace pas la vérification auprès de la source officielle.
