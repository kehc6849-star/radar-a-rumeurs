## Règle de mise à jour

À chaque lot de code livré :
1. mettre à jour le [CHANGELOG](../CHANGELOG.md) ;
2. cocher la [feuille de route](07_ROADMAP.md) ;
3. compléter [Utilisation de l'IA](03_AI_USAGE.md) si un modèle ou une API est ajouté ;
4. compléter [Règles de détection](04_DETECTION_RULES.md) si une règle change ;
5. noter toute décision importante dans le [journal des décisions](09_DECISIONS_LOG.md).
